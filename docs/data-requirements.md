# 人物考据数据需求 · 江山行止

> 回答一个问题：**做一个人物的行迹考据，到底需要哪些数据？**
> 判据不是"有没有"，而是"这条数据在考据时会不会被用到"。
> 落库实现见 [database.md](database.md)；数据源见 [sources.md](sources.md)。

## 0. 三条准入判据

一条数据值得入库，必须至少满足一条：

1. **能定站**：能推出"某年某人在某地"。
2. **能定年**：能确定或收窄时间（含年号、区间、上下限）。
3. **能验伪**：能用来否定一个说法（矛盾、异文、时间冲突）。

只满足"看着有用"的（比如人物画像、评价语），**不入库**——它们是展示素材，不是考据依据。

## 1. 六类数据

### A. 人物身份（identity）

| 字段 | 考据时的用途 | 粒度 | 来源 | 落表 | 优先级 |
|---|---|---|---|---|---|
| 姓名 | 检索入口 | 一个 | 史传 / CBDB | `person.zh` | P0 |
| 别名、字号、号、谥号 | 史料常以字、号相称，缺了会漏检 | 多个 | 史传 / CBDB / Wikidata | `person_name` | **P0** |
| 生年、卒年 | 时间线锚点 | 年 | CBDB / 年谱 | `person.born/died` | P0 |
| 生卒精度 | 区分"确知"与"约""异说" | 枚举 | 多源比对 | `born_precision/died_precision` | P0 |
| 生卒依据 | 谁说的、几卷 | 一条一证据 | — | `claim` + `evidence` | P0 |
| 籍贯、郡望 | 归属地，影响地名判定 | 一个 | CBDB | `person` 待加 | P1 |
| 葬地 | 行迹终点，常与方志互证 | 一个 | 方志 / 墓志 | `person` 待加 | P2 |
| **职官履历**（时间 + 官职 + 地点） | **最有价值的行迹骨架**：任某地知州 = 某年在某地 | 多条 | **CBDB** | `office` 待建 | **P1（缺它最痛）** |
| 亲属 | 交叉验证（谁为他写墓志、谁随行） | 多条 | CBDB | `relation` 待建 | P1 |
| 交游、师承 | 赠答诗能定"某年某人在某地" | 多条 | CBDB / 别集 | `relation` 待建 | P2 |
| 著作目录 | 作品层的候选清单 | 多条 | 目录书 / CBDB | `work` | P1 |
| 外部 ID（CBDB / Wikidata / VIAF） | 消歧与跨库对齐 | 各一 | Wikidata `P497` | `person.cbdb_id` 等 | P0 |

### B. 行迹（movement）

| 字段 | 用途 | 粒度 | 来源 | 落表 | 优先级 |
|---|---|---|---|---|---|
| 年 + 地 + 事 三元组 | 行迹本体 | 一站一条 | 年谱 / 史传 / 作品题名 | `stop` | P0 ✅ |
| 年份精度（约 / 年号 / 区间） | 防止把"约"写成确数 | 枚举 | — | `stop.year_note` | P0 ✅ |
| 古地名 → 今地名 | 读者要能对上现代地图 | 一站 | CHGIS / 地名库 | `stop.place_*` | P0 ✅ |
| 坐标 | 画在地图上 | 一站 | CHGIS 治所 | `stop.lng/lat` | P0 ✅ |
| 依据 | 每站必须有出处 | 一站一条 | — | `stop.source` | P0 ✅ |
| 站间承接语 | 让行迹可读 | 一段 | 自撰（据史料） | `journey` 相关 | P1 |

### C. 作品（works）

| 字段 | 用途 | 来源 | 落表 | 优先级 |
|---|---|---|---|---|
| 题名 + 异题 | 引文按书名匹配 | 别集 / 总集 | `work.key/title_zh` | P0 ✅ |
| 文体 | 决定渲染与"摘录"标记 | — | `work.genre` | P0 ✅ |
| 作年 + **year_kind** | 区分作年与所述之年 | 考证 | `work.year/year_kind` | P0 ✅ |
| 作地 | 与行迹站点互证 | 考证 | `work.place_zh` | P0 ✅ |
| 全文 | 阅读 | 别集 | `work.body` | P0 ✅ |
| 赠答对象 | 交游证据 | 题名 | `work.recipient` 待加 | P1 |
| 异文校勘 | 验伪与版本 | 多版本 | `work_variant` 待建 | P2 |
| 出处 | 卷次、版本 | — | `work.source` | P0 ✅ |

### D. 地理（place）

| 字段 | 用途 | 来源 | 优先级 |
|---|---|---|---|
| 历史建置（某年叫什么、隶属何州） | 地名判定；同一地唐宋元不同名 | **CHGIS** | **P1（错地名最伤）** |
| 治所坐标 | 地图落点 | CHGIS | P1 |
| 同名异地 | 消歧（"东山""新安"遍地） | 地名库 | P1 |
| 今地名对应 | 读者定位 | 民政部地名库 | P2 |

### E. 文献（texts）

| 字段 | 用途 | 来源 | 优先级 |
|---|---|---|---|
| 书名 + 卷次 + 篇名 | 引文定位 | — | P0 ✅（仅字符串） |
| 段落切分 + 锚点 | 引文精确定位到段 | 自行切分 | **P1** |
| 版本（底本、录入来源） | 诚实标注 | — | P1 |
| 异文 | 校勘 | 多版本 | P2 |

### F. 证据与断言（claims）

| 字段 | 用途 | 优先级 |
|---|---|---|
| 断言（主体 + 谓词 + 值） | 每个结论一条记录 | P0 ✅ |
| 证据（原文片段 + 出处 + 等级 A–D + 立场 support/contradict） | 让冲突显形 | P0 ✅ |
| 研究线索（候选站、取舍理由、未采纳说法） | 下次不用重做 | **P1（现在只散落在对话里）** |

## 4. P0 首批入库清单（现在就能做）

1. **人物别名表**（`person_name`）：从 Wikidata 与 `PERSON_PROFILES.aliases` 灌入
2. **职官履历表**（`office`）：先建表，等 CBDB
3. **研究线索表**（`research_note`）：把蒋捷的取舍与冲突先落库
4. **原文段表**：先入《竹山词》两首 + 《宋史·苏轼传》一卷，跑通"引文定位"
5. **断言补齐**：8 位主角的卒年、籍贯各建一条 claim + 至少两条 evidence

## 5. 一条判据的副产品

按上面标准筛一遍，**有三类数据我们明确不要**：

| 不要 | 理由 |
|---|---|
| 人物画像、肖像 | 展示素材，不能定站/定年/验伪 |
| 后世评价、文学史地位 | 无助于考据，且易生争议 |
| 民间传说、轶事 | 来源不可核，会污染证据链 |
