# 行迹考据 SOP · 江山行止

> 一条行迹怎么从"这个人是谁"做到"九站可读"，且每一站都经得起追问。
> 数据源清单见 [sources.md](sources.md)；数据契约见 [dev-guide.md](dev-guide.md) §3。
> 本文是流程，不是可选建议——`_validate_data.cjs` 会把缺 source 判为错误。

## 0. 先判断值不值得做

做一条行迹的成本≈读一份年谱。所以先问三个问题：

1. 这个人的行止能考出 **≥3 个不同地点**吗？
2. 他（或与他直接相关的史料）留下了**可引的文本**吗？
3. 有**一条主线**能串起来吗（贬谪、求法、北伐、流亡、仕宦）？

三问有二否，就不做行迹，只做「人物条目」——宁可少一条，不要凑一条。

## 1. 五步法

### 第一步：定身份

| 要填 | 来源 |
|---|---|
| 姓名、字、号、别名 | 史传本传 → Wikidata 别名 |
| 生卒年 | CBDB / 年谱 → **Wikidata 交叉** |
| 籍贯 | CBDB / 史传 → Wikidata `P19` |
| 身份（诗人/僧人/使节/帝王…） | 史传用语，不自行归纳 |

输出：`PERSON_PROFILES` 条目，`span` 取可支撑的边界，courtesy 里写明"无确考"。

### 第二步：摆站点候选

按优先级找证据，**一条证据一个候选站**：

1. **年谱**（若有）——最可靠，能定年定地
2. **正史本传**——定大事，未必给地名
3. **本人作品的题名/序跋**——`《一剪梅·舟过吴江》`=到过吴江；`《宿龙游朱氏楼》`=住过龙游
4. **他人赠答、送别诗**——能定"某年某人在某地"
5. **方志、墓志、寺观记**——补细节
6. **今人研究**（专著、论文）——最后用，且要标为研究转述

### 第三步：定地点与坐标

- 用 **CHGIS** 查该年份的建置名（同一地，唐宋元可能不叫一个名字）
- 古名 → 今名 → 坐标
- 拿不到精确治所时，退回府/州级坐标，并在叙述里写"州治"

### 第四步：定年份精度（关键）

**不要为了填数字而造精度。** 按这张表落：

| 情形 | `year` | `certainty` | 叙述里怎么写 |
|---|---|---|---|
| 史料明载年月 | 精确年 | `confirmed` | 直接写年份 |
| 只有年号（如"元丰五年"） | 换算年 | `confirmed` | 写年号 + 括注公历 |
| 只能定到区间（"密州任上"） | 区间中点 | `probable` | 写"X—Y 年间" |
| 只能由词题定地不定年 | 估计年 | `probable` | **必须写"约"** |
| 完全不可考 | 删除该站 | — | 不写，别凑 |

### 第五步：交叉验证

- 有两源一致 → 可用
- 两源冲突 → **并列，不裁决**（见 sources.md 的蒋捷卒年样例）
- 只有一源 → 可用，但要标 `singleSource: true`

## 2. 证据分级

每条叙述在数据里可以带 `evidence` 字段（可选，供校验与界面使用）：

| 级 | 含义 | 例 |
|---|---|---|
| **A** | 正史本传 / 年谱 / 本人作品明载年月 | 《宋史·瀛国公纪》德祐二年 |
| **B** | 本人作品题名含地名（可定地不定年） | 《高阳台·江阴道中有怀》 |
| **C** | 他人赠答、方志、墓志 | 送别诗、地方志 |
| **D** | 今人研究推定 | 杨景龙"卒于1314之后" |

**规则**：一条行迹里若全是 C/D 级，不做。A 级不足两站的，行迹标"†"。

## 3. 落库检查表

做完一条行迹，逐条打勾：

- [ ] 每站 `source` 具体到卷次或篇名（不是"《宋史》"三个字）
- [ ] 生年无确考 → `courtesyZh` 写明"生卒年无确考"
- [ ] 由题名定地的站 → 叙述里有"约"
- [ ] 冲突的说法 → 两句都写出来，不合并
- [ ] 坐标来自 CHGIS 或对应府州治所，不手抄
- [ ] `node scripts/_validate_data.cjs` 通过
- [ ] 读本导语与承接语各带 `source`

## 4. 明确不做的事

| 不做 | 为什么 |
|---|---|
| 给史料没写的人算年龄 | 我们不做推算（苏轼"二十一岁"就是这么错的） |
| 把"约"写成确数 | 精度是承诺，不是排版 |
| 合并两种说法成"约 1305—1314" | 那是自造区间，两个说法都不是这个意思 |
| 用推断补站凑数 | 一条假站毁掉整条行迹的可信度 |
| 从有版权的库抓数据 | 台账里标 ❌ 的一律不用 |

## 5. 一个人要花多久（实测）

蒋捷（9 站）：查证+写作约 1.5 小时，其中**找齐可考地点**花了一半时间。
第一次做苏轼（11 站）更快，因为有年谱可依。

**结论**：有年谱的人便宜，没有年谱的人贵；贵的那类，先做"人物条目"再做行迹。
