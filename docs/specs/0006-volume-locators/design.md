# 设计

新增显式卷题定位清单。只定位原书名+卷号原字符，不根据FILE/JUAN数字猜卷、不据两个标头自动切出核定卷文。记录最近的源页标记作为辅助，不把电子页号冒充已核影像叶码。

复用research_ingest.record_snapshot保存volume_heading候选，关联信息含source_snapshot和原始文件身份；不新增公开正文或修改上游原件。整理时从库内原件回读标题范围和卷号，核验阶段比较完整候选集合及字节。新集合是研究编目数据，不属于已审学术事实。

作品证据仍用已有witness/audit记录与原态摘引；逐项保留原始差异，不把去标点、异体归一或相近匹配当逐字等同。短句需要篇题上下文佐证，生成审校方式显著保留。

旧引书名保留在citation及研究searchLog中，显示未核提示，不静默换成推定的已核版本。四句教撤出默认1521后仍保留dating旧记录，口授、记录、作品编写时间分别待核。先备份本地编辑库再用增量导入，地图生成物由poem-data生成；无新增前端依赖。
