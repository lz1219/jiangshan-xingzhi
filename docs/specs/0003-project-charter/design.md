# 设计

项目级规范统一维护在 poem-data/docs/project-charter.md 与 editorial-policy.md；地图 docs/design.md 保留地图仓库职责和上游保护规则，通过相对链接指向共同规范。

三种用途共用作品、人物、时地、版本、证据与修订记录；默认阅读简明，研读和专业考据逐层展开，必要的摘录、待核和AI标识始终保留。

原文、导读、译文、注释、赏析、古人评点、背景与研究推测的职责分开。译文独立于大意；生成方式和审校状态覆盖全部解释层；学术质量按具体核验范围表达。三篇样板保留为后续通用内容模型的验证集。

本批只制定和对齐文档，不变更当前 schema、迁移或发布规则。新的内容模型与阅读展示另由 R-13 实施；R-11 的来源和事实核查持续推进。
