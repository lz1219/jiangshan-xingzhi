# 需求 · 文献、人物与行迹的关联

R-17：统一作品、人物与文本见证的身份，区分引文出处与历史事实；精选 JSON 和原语料库保留现有职责。苏轼《定风波》先作为待核样板。

## 验收

- 候选关系记录两端稳定标识、原文或数据快照、固定来源、差异及依据；区分未审候选和已确认事实。
- 真实库读回、重复导入、异常回滚；正文和既有记录不重写。
- 原文、版本、人物或站点变化时旧关联不展示；跨库引用在导入和读取时校验，不声称具有跨库外键。
- 对作品与语料、站点的浏览保持候选标识，不据站点引文推断作年、作地或亲历。
- 迁移不破坏既有译注或地图 JSON 发布契约；完整释义、古注及研究关系后续单独验收。
