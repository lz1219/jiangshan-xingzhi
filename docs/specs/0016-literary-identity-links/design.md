# 方案 · 跨库候选关联

原语料 `jiangshan` 与编辑库 `jiangshan_web` 分开，poem-data JSON 是精选内容发布真相。候选 JSON 保存人物、作品、诗词见证和站点的标识、固定来源、哈希、引文与差异；线上语料库三张候选表分别连接语料人物、诗词与外部站点键。语料实体使用库内外键，跨库部分由 JSON、编辑库和来源校验，不冒充跨库外键。

先验证苏轼《定风波》：语料112266与精选见证正文存在“潇洒／萧瑟”异文，站点8只表示引用关系；所有映射为候选，不进入确定事实索引。旧版编辑库的作品来源与当前 JSON 曾不一致，已按用户部署要求备份并修正；今后版本失配时接口必须隐藏关联，不得绕过校验。

原始正文和旧译注不迁移。读取时重新检查作品、人物、版本、诗文哈希、来源和站点；来源不符不回退旧内容。待验证的 UI 使用候选标识，发布前仍需按两站流程确认。诗词与典籍通用译注、可修订事实和其他人物映射不属于本次样板已完成范围。

## 人物专题入口（2026-11-05）

以人物作为阅读入口，复用现有人物、作品和行迹记录：人物页展示精选作品及进入行迹的入口，作品页作者可返回人物；行迹页仅在站点引文书名与此人物的精选作品键唯一相同时提供作品入口，标注“关联待核”。这只是根据现有引文和作品键生成的导航候选，不证明所引内容逐字一致、作年作地或亲历；同名或未匹配时不显示链接。原有定风波跨库候选仍独立执行来源、哈希及版本检查，不能由新导航取代。

苏轼页面先展示已有《定风波》《水调歌头》《念奴娇》三个入口；其他人物复用相同布局。此次不新增生平事实、原典或正式证据，人物生平和行迹来源、作品正文与异文仍待核。已在本地桌面和手机验证人物→作品→人物→行迹→所引作品，线上两站及人物→原典完整链仍待验证。

人物专题继续完善：苏轼页从已有行迹中选取杭州、密州、黄州、惠州四个站点，显示记录中的站点年份、地名、原有引文及来源状态；点击站点进入对应行迹位置，点击作品入口沿唯一标题匹配进入精选作品。节点日期仅是现有站点日期，不是作品写作年份；上游引用和地点仍待核。四个节点来自当前数据，不把摘要改写成已考证生平，也不新增史实。异步加载失败时保持人物页其余内容可读。


## 数据库驱动地图过渡（2026-11-10）

项目持有人要求以线上数据库为准；作品、典籍和版本的统一是目标，既有跨库候选仍为过渡。地图生成器接受数据库导出的临时数据目录，默认 JSON 接口暂时兼容；临时导出不能视为独立人工维护库。必须核对数据库版本、作品与站点标识、数据差异、证据状态和地图阅读后才切换。线上数据库只读导出及隔离地图生成的结果、当前架构不兼容和48篇对象差异见 poem-data/docs/reports/database-atlas-export-20261110.md；未删除旧数据或发布。
