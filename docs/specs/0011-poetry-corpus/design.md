# 设计

原corpus_poem继续存正文；增加corpus_poem_origin关联现有corpus_ingest_batch/edition，保存固定源文件哈希、JSON指针、原段落Unicode范围、原字段及质量状态。不把诗词正文写入精选读本JSON。

一个共享corpus_poems工具处理有明确规格的固定JSON集合，复用原备份、分块COPY、内容指纹和外键保护。首批仅已有空书目53、固定宋词22文件，核全部输入哈希与Git blob，不能换参数套其他来源；逐记录完整相同仅合并位置，异文保留。失败整个事务撤销，不重试写操作或提高超时。

API增量返回来源、序文、标签和质量状态；纸本未核与替换字符提示保留。旧唐诗/元曲无新增来源不被追认，原字可能为简体，界面不统一称繁体。诗词书目支持分页检索，不冒称有卷目；词牌不伪装成已核篇题。补库与阅读验证包含全部记录回读、重复位置、序文/标签以及回滚保护。
