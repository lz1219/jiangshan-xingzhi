# 方案

延续research_ingest隔离工作区，为非Git来源增量补provider/revision_id；Git提交保留原约束，维基修订不伪造Git哈希。原始捕获响应仍按SHA-256存储，维基文本另存原态字节。

采集维基固定oldid/API修订，逐页记录页名、pageid、revid、时间、URL和响应/文本哈希。取得原目录后按章核清单及卷题，保留转录和底本待核状态。

既有Git解析器保持v3身份，新增维基修订解析器；总批次登记支持的解析器集合。派生表按本批来源及其解析器读取，能发现多余行并排除旧解析器。维基段落先保留整个原始页面范围，不把模板、编辑标点或换行冒充原典段落。

来源调查日志及正文候选追加保存；证据能定位原句才形成见证候选。文献站/地图公开正文不随原件采集自动变化。
