# R-11 地方志补采：龙场站

为王阳明龙场/贵阳行迹提供可定位地方志资料。按现有站点缺口选《贵州通志》，保存版本、范围与检索边界，不把清代记载倒作明代亲历或现代精确坐标。

- 固定电子原件提交及文件哈希，核目录和实际卷题。
- 文本、影像、机构书目分别检索并记录成功/受阻、权限和同源关系。
- 原句候选附卷篇、原页标和真实字节；AI辅助解释明确待人工审校。
- 地方志、人物年谱及后世纪念设施分别陈述；不能据后出纪念地认定现场。
- 实际进入隔离研究库后整理和全量回读，原公开正文与地图默认站点不因候选材料自动更改。
- 来源质量核查允许subject.type=source，key必须为台账已有来源；JSON、数据库准入与读取一致，旧对象格式兼容。
