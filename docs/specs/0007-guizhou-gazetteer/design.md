# 设计

复用采集清单、来源台账、source-discovery及witness/audit研究修订。完整原件按哈希封存并进入research_ingest；研究候选指向现有journey/stop，不新增确定路线。

卷数依原件目录与实际卷题核对，卷首/提要另计。机构藏本的缺叶、装帧与版本只属于该藏本，不迁移到Kanripo或维基转录。影像入口多版本混列时按文件元数据选择，不按同名认同版。

卷28质量记录关联来源自身，不挂在人物名下。研究schema增加source枚举，Node闸门与Django准入均核来源存在；不增加数据库字段。既有研究页按通用subject过滤，支持来源检索和固定修订链接，隔离库复用已有来源快照关联。
