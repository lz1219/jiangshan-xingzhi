# 诗词阅读样板与页面基调

用户于 2026-11-05 调整优先级：先设计页面、确定整体基调；先做文献站，地图关联沿用既有能力。

## 设计

以安静、清晰的中文阅读为中心：首页以文献馆导读和苏轼人物样板为入口，目录用低对比的分栏组织，人物、作品与正文通过一致的文字层级和纸色建立连续性。标题和作者建立篇章感，正文保留充足行距；来源、反推繁体、系年及摘录状态始终可见或明确入口展开。不要把页面装饰或技术术语放在阅读之前。电脑和手机共用内容结构，适配深色模式，不引入构建工具或 npm 依赖。

用户明确现阶段优先页面设计，既有栏目和版式均可重新设计。首页以导读、人物专题和馆藏索引组织；山水线条为装饰，不代表真实地理或历史路线。后续继续从整体阅读体验评估，不把当前首页样板视为最终定稿。

作品阅读先呈现原文，再展开对应译注，辅助操作放在阅读之后。所选原文与译注段落同步突出；手机沿用底部抽屉，保留关闭和待核状态。旧解释继续可按需展开，不因重新设计丢失。

手机打开精选作品、人物或行迹详情后暂时收起列表，并提供返回列表入口；不改变桌面分栏。返回后保留筛选和列表，便于继续选择。

平板和窄桌面保持目录与阅读区并列，目录可独立滚动；手机仍使用列表与详情切换。中等屏幕的搜索和筛选允许换行，不以超宽内容挤出视口。

文献导航区分精选阅读（作品、人物、行迹）与馆藏检索（作者、典籍）；静态模式无后者时不显示空分组。搜索区减轻盒状视觉，保留筛选与可见的当前栏目。

视觉样板尝试克制的玻璃拟态和新拟态：导航与手机译注抽屉使用半透明模糊，辅助按钮使用柔和凸起；正文保留清晰对比，深色模式与不支持模糊的浏览器有对应底色。该方案为本地试验，尚需实际审美反馈。

2026-11-06 按用户要求大幅调整视觉样板：以山水青绿、书页和半透明界面统一首页、导航、目录、人物及作品阅读；正文仍使用高对比实色。主题样式独立于页面结构，静态导出包含该样式；当前仅本地预览，不视为最终设计定稿。

随后按用户要求转为淡水墨与玻璃、新拟态结合：自绘山水底图、半透明磨砂层与柔和内外阴影用于首页、导航、卡片、阅读辅助和考据页；正文保持较高对比，深色模式独立配色，静态导出携带底图资源。

当前本地配色调整为宣纸暖白、淡墨灰与少量朱砂，深色采用墨灰；配色仍为待用户评估的设计样板。

视觉效果提供完整、柔和、静态三档并在两页共享选择；默认柔和仅首页播放一次流光，阅读区稳定，系统减少动态效果优先。2026-11-06 已部署8081；考据页通过公开静态索引、来源台账与历史快照恢复记录阅读，研究 API 尚未部署，详见 poem-data/docs/reports/research-release-20261106.md。

典籍阅读沿用同一视觉语言，以卷题、版本状态、阅读设置、正文和研读侧栏区分层次；手机译注底部展开。考据页用目录与记录并列，保持来源、审校、反证和引用信息可见；无深链时默认打开当前筛选结果首条，有深链时保留指定修订，手机选择记录后滚动到正文。首页、典籍与考据三处的阅读和研究状态均按实际数据展示。

苏轼专题以人物概览、行迹节点、所引作品、完整作品列表和研究工具组织阅读；行迹节点的年份和引文来自现有数据，待核提示常显，不据此推导作品写作地。具体链接与边界见 `../0016-literary-identity-links/design.md`。

专题视觉以人物题签和纵向行迹线组织阅读：节点年份、地点、引文、来源及跳转分层呈现，手机使用同一顺序和紧凑布局；装饰性文字不承载历史信息。

诗词原文可逐段点击：桌面在原文下方显示对应译文与相关注释；手机使用底部非模态抽屉，保留部分原文画面，内容可滚动，支持关闭及键盘退出。赏析可展开，显著标示 AI 生成且未经人工审校。已经有匹配译注时，将旧大意、注释与赏析收进默认折叠的“原有整理内容”，供对照；无样例或版本失配时默认展开原有内容。旧内容不能冒充新译文或古人评点。来源研究记录、语料对照及行迹入口保留。地点待核时不得显示为已确知的作地。

## 数据与安全边界

语料对照仅按同作者、同题及清洗后首句的前 8 至 12 字筛选候选，不用相同词牌直接认定同一首词；无匹配时提示可能有异文或尚未收录。页面标示候选和未经人工审校，短原文不自动匹配。该规则可能漏掉首句有异文的版本，不等于正文、作者或底本已核定。

11 篇候选仅用于本地阅读样板，独立文件记录来源作品版本键、原文、简体原文、哈希、模型及审校状态；不覆盖原文或既有作品字段。页面仅在当前作品的版本和两种原文逐段匹配时展示；变动后不自动继承。该匹配只验证关系，不代表底本、译文或史实已获人工核实。部署和后续入库按既有确认流程，不能把样板称为已上线或学术审定。

## 验收

桌面和手机检查正文、段落切换、抽屉关闭、注释、赏析、来源与 AI 状态；无样板或版本失配时原页面仍可使用。检查静态页面与动态作品数据，校验数据来源及原文锚点。后续确定最终排版后，另行完成任意选句定位、繁简切换、人工审校和可信来源核验。
