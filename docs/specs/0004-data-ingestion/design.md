# 设计

在现有语料库增加 research_ingest 工作区，与公开阅读接口使用的 public 表隔离。只增原件与结构化派生数据，不改已有公开正文或事实。

分三条命令：land 将原始ZIP、文件字节、元数据和JSON快照实际入库；organize 从库内原件解析版本、卷篇、页标与字节范围，建立策展对象关系和引文位置；verify 从库内读回，独立核对本批输入清单、所有字节、关联、重复与公开表指纹。

按内容哈希确定原件、快照与批次身份；事务锁、写前备份、不可变原件和幂等插入保护数据。原页保留，不按硬换行伪造自然段。卷首、附录及不能分类的文件分开计数；无法确定的版卷信息记缺口。内部研究材料留在非公开工作区，报告不暴露原文或内部正文。

采集计划、书目台账和分支调查均保存原始响应及哈希。记录身份包含父原件路径与哈希，来源快照包含完整元数据；派生版卷页按解析器版本并存，兼容移除旧版妨碍并存的唯一约束，原始行保留。大文件按负载写入、分片回读，避免公网语句时限导致虚假完成。内部标题/编号不冒充原卷号，SBCK保留FILE字段及正文卷首候选。
