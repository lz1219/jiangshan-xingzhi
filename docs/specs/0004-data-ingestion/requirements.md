用户当前目标：先落库数据，整理数据，再验证。先处理已取得的完整资料和现有策展/研究数据，不先改界面，不以摘要或少量样板代替原件入库。

范围：原有六部及按缺口新增二十一部，共27个原典仓库的29个固定版本快照、完整缓存ZIP及所有文件、来源目录、38条原书目、作品/人物/行迹/站点快照、公开及内部研究历史、版本与出处元数据。保护已有公开原文和事实，待核资料不得自动公开。同源分支不重复计独立典籍或佐证。

书目须区分出处占位、卷篇记录和诗歌库记录。实际原件题名与目录不符、JUAN编号重排或只覆盖部分原书时列明问题；不按仓库题名或文件数宣称全本，未取得资料保留后续线索。
