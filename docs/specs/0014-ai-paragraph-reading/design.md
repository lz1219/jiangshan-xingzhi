# 方案 · 先固定决定，再验证契约

规范集中poem-data/docs/ai-reading-policy.md，项目总纲与编纂规范引用该细则；aicoding只负责执行入口，不复制产品规则。地图看板维护唯一排序。

复用全文库的版本、卷篇、段落及来源，先核自然段与现有字段，再决定译文、注释、赏析、生成及审校修订的最小增量契约。注释锚定来源原字，转换只影响阅读；旧大意、源校记、古人评点和AI解释分别处理。

首期批量生成候选、检查并存储，网站直接读取；当前两段样本已入原语料库，详见poem-data/docs/reports/ai-reading-0002.md。桌面正文与侧栏并读，手机从底部展开；选择同一段文本或点击段旁译注打开，未整理段落显示待补。来源编号、校记和AI译注分开，阅读切换不改变来源原字；复杂繁简位置和跨段选择仍待解决。
