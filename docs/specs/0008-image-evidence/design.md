# 设计

影像完整原件和平台渲染预览分别作为隔离资产。来源台账保存imageAssets身份及预览页序/哈希；imageObservations引用已登记资产，不把图片OCR或目读写成verifiedQuote。研究修订仍以JSON快照入库，不新增默认事实。

准入核来源及资产登记；全量回读另核原件SHA1、元数据文件身份、预览URL页序与真实字节。研究页展示AI目读、未审状态、原件及预览出处，只提供来源链接，不代发整本影像。逐项人工核验需要具名历史，AI复核不升级。

龙场年谱、东洞诗及何陋轩记保存独立原态摘引，补充旧地方志记录的证据边界。叙述只报告这些文献如何记载；源数据修订由overlay生效，原上游引文不改。
