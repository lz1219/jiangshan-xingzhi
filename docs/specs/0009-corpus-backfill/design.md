# 设计

poem-data是实施仓库。新增确定性Kanripo解析与补库工具，默认只读预览；明确apply才在备份与锁保护下写入。旧导入器会覆盖正文/删除段落，本批不使用这些写路径。

旧book_id保留；独立版本信息、卷序、来源原件及段落原页范围采用增量关联记录。完整原件已有research_ingest与哈希缓存，正文实际写旧text_unit/paragraph，注本保留古注并提供结构分层。

来源页作为机器切分单元明确标注，不宣称原作自然段。全文拼合及古注分层应能重构对应展示文本，原态仍可按源文件字节回读。展示层不擅自加标点或改字。

每批固定输入身份并记录新增ID，验证实际数据库内容、阅读API及重复导入。回滚先核新增行未变化且无后续外部引用，再只撤本批新增；备份不回显凭据。

首批范围细化：转录的十表卷十三至二十二存在大量空页，整段暂不入库；先收提要、序及卷一至十二、二十三至一百三十，共122卷篇单元、3,544来源页，其中5个空电子页保留待核状态。复用既有edition表，新增corpus_ingest_batch、corpus_unit_origin、corpus_paragraph_origin三表关联旧主表。括号分段仅描述源录结构，不自动认定注者。

回滚先锁批次及目标edition/text_unit/paragraph和来源行，再校验与查外键，阻止普通编辑和后续引用在检查与删除之间进入。首次验证在同一事务中真实执行导入、重复导入、保存点内的改动/引用拒绝检查、回滚、重入；事务最终只提交最后一次内容。API增量返回版本、收录范围、来源页和待校信息，阅读页沿用现有样式明确缺口；补通既有scope=text检索。

第二批《汉书》仍复用旧book_id=8。固定KR2a0007 WYG输入，先收十二本纪：卷一上/下及卷二至十二共13正文分卷，另列13个本版考證；不把考證计入班固正文卷数。原录&KR…;缺字标记原样保留、统计并提示，不自行解码。共享写入/回滚工具从固定解析计划取得bookId及版本名，史记既有manifest与batchId保持原样；仍只支持各书首批空书目，不因此支持向已有正文任意合并。备份前锁书目行，以阻止并发外键写入越过空书检查。其他卷段/卷首后续分批，不宣称全书完整。
