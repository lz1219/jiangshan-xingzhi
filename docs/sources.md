## 用法约定

1. **人物基础事实**先查 Wikidata（快、结构化、CC0），记下 QID 与 CBDB ID。
2. **要点级事实**（仕宦、亲属、确切年月）到 CBDB 核；CBDB 没有的，再查别集与史传。
3. **地名与坐标**用 CHGIS 对应该年份的建置，再落到今地名；不手抄坐标。
4. **引文**只用公版底本（维基文库 / ctext），并标卷次。
5. **交叉核对**：搜韵、编年地图只用来发现"是不是漏了"，不作为出处。
6. 每个事实**尽量两个独立来源**；只有一个来源时，在数据里标 `singleSource` 并在界面注明。

## 已知的冲突样例（留存记录）

蒋捷卒年，三个来源三种说法：

| 来源 | 说法 |
|---|---|
| Wikidata（Q15725559） | 1301 |
| 通行百科 | 约 1305 |
| 杨景龙《蒋捷词校注》（经《新华日报》2024-07-19 转述） | 1314 年之后 |

处理方式：**并列，不裁决**。数据里 `span` 取 `[1245, 1314]`，人物小传写「卒年有异说」，末站叙述并列两说。

## 工具

- `scripts/_wikidata.ps1 -Name <人名>`：按人名查 Wikidata，输出 QID / CBDB ID / 生卒 / 籍贯坐标。
  需代理：默认 `http://127.0.0.1:7897`，可用 `-Proxy` 覆盖。
